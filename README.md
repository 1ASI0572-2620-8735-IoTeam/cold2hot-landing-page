# Cold2Hot · Landing Page

Landing page de **Cold2Hot**, la caja de delivery inteligente de **IoTeam** (UPC · 1ASI0572 · NRC 8735).

Sitio estático desarrollado con HTML5, CSS3 y JavaScript vanilla.

## Funcionalidades

- Calculadora de ROI (US01)
- Planes de suscripción con contacto a ventas (US02)
- Cambio de idioma español / inglés (US18)
- Diseño responsivo

## Estructura

```
index.html        Página principal
css/styles.css    Estilos
js/main.js        i18n, calculadora ROI, menú y animaciones
assets/img/       Logo y fotos del equipo
```

## Ejecución local

Abrir `index.html` en el navegador. Para desplegar, publicar la raíz del repositorio en GitHub Pages o Vercel.

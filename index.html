El problema

La última milla es donde se pierde la calidad… y la confianza

Las mochilas y cajas pasivas no reaccionan al tráfico, la distancia ni el clima. Y cuando un cliente reclama, nadie tiene pruebas de lo que pasó en el camino.

❄

Comida fuera de temperatura

En trayectos de más de 15 minutos, la comida caliente llega tibia y la fría se descongela. Aislamiento estático, sin control activo.

⚠

Pedidos manipulados

Cremalleras, velcros y stickers se abren o se replican. No hay forma de saber si el pedido fue abierto en ruta.

⚖

Disputas sin evidencia

Reembolsos, reclamos falsos de no entrega y penalizaciones injustas al repartidor por falta de un registro auditable.

La solución

Una caja inteligente, una app para el repartidor y un panel para tu operación

Cold2Hot integra hardware IoT, una aplicación móvil y una plataforma web para asegurar la cadena de custodia térmica y física de cada pedido.

🌡️

Regulación térmica activa

Asigna el perfil frío o caliente desde el panel al despachar. El sensor DS18B20 (±0.5 °C) reporta la temperatura cada minuto.

🔐

Desbloqueo por código OTP

Un cerrojo solenoide mantiene la caja cerrada hasta que el repartidor ingresa en su app el código único generado por el restaurante.

🛡️

Seguridad de dos niveles

Un sensor magnético y uno infrarrojo distinguen una tapa mal cerrada (aviso preventivo) de una extracción real del pedido (alerta crítica).

📸

Evidencia fotográfica

El repartidor cierra cada entrega con una foto que queda asociada al envío. Protege al restaurante y al repartidor.

📊

Monitoreo en tiempo real

Dashboard con temperatura, batería y estado del cerrojo de cada caja activa, más alertas push y web al instante.

🧾

Auditoría inmutable

Un único reporte con la curva térmica del viaje, la hora exacta de apertura y la foto de entrega para resolver cualquier reclamo.

Cómo funciona

Del despacho a la puerta en cuatro pasos

  1. 1

    Crea el envío

    Desde el panel web registras el pedido, eliges el perfil térmico y se genera el código OTP.

  2. 2

    La caja cuida el pedido

    La SmartBox regula la temperatura, se bloquea y envía telemetría continua durante la ruta.

  3. 3

    Desbloqueo en destino

    El repartidor se conecta por Bluetooth desde la app e ingresa el OTP para liberar el cerrojo.

  4. 4

    Entrega con evidencia

    Foto de entrega, cierre del ciclo y reporte de auditoría disponible al instante en el panel.

Dentro de la SmartBox

Hardware abierto, confiable y listo para la calle

ESP32

Microcontrolador

ESP32 NodeMCU con Wi-Fi y Bluetooth Low Energy para telemetría y control del cerrojo.

DS18B20

Sensor de temperatura

Rango de −55 °C a +125 °C con precisión de ±0.5 °C en el compartimento interno.

Reed + TCRT5000

Seguridad de dos niveles

Sensor magnético de tapa e infrarrojo de presencia del paquete para evitar falsas alarmas.

12V DC

Cerrojo solenoide

Bloqueo mecánico que solo se libera con un código OTP válido.

Edge

Resiliencia sin señal

Un nodo edge con base de datos local guarda los registros cuando se pierde la cobertura y los sincroniza después.
